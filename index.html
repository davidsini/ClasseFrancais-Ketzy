Grammaire: Les adjectifs possessifs

Une façon simple de le voir

Imagina que cada persona tiene "etiquetas" para sus cosas. ¡Solo necesitas saber 2 cosas!

1. ¿Quién es el dueño?

Esto define el grupo de etiquetas.

  • Si el dueño soy YO (Je) → `mon, ma, mes`
  • Si el dueño eres TÚ (Tu) → `ton, ta, tes`
  • Si el dueño es ÉL/ELLA (Il/Elle) → `son, sa, ses`

2. ¿Cómo es el objeto?

Esto define la etiqueta exacta.

  • Si es 1 objeto masculino → `mon, ton, son`
  • Si es 1 objeto femenino → `ma, ta, sa`
  • Si son varios objetos → `mes, tes, ses`

¡El truco! Con palabra femenina que empieza con vocal, usa la etiqueta masculina: mon amie, ton idée.
